# Template format guide / Guía de formato

## English

### File naming

`hook-[format].md`

Accepted formats: `list`, `fact-expand`, `story`, `question`, `contrast`

### Required sections

Every template must include:

1. **Header metadata** — duration, format, retention note
2. **Structure block** — the skeleton with named slots
3. **Script** — the fill-in version with `[BRACKETS]`
4. **Filled example** — a real, complete example (not lorem ipsum)
5. **Usage notes** — 3–5 practical rules for this specific format

### Writing rules

- No emojis in the script body (compatible with AI voiceover)
- Max 2 sentences per beat
- Brackets use ALL CAPS: `[HOOK]`, `[POINT 1]`, `[CTA]`
- No filler phrases ("In today's video", "Don't forget to like")
- CTAs must be a question or a direct action — never "subscribe for more"

## Español

### Nombres de archivo

`hook-[formato].md`

Formatos aceptados: `lista`, `dato-expand`, `historia`, `pregunta`, `contraste`

### Secciones obligatorias

Cada template debe incluir:

1. **Metadatos de cabecera** — duración, formato, nota de retención
2. **Bloque de estructura** — el esqueleto con los slots nombrados
3. **Script** — la versión rellenable con `[CORCHETES]`
4. **Ejemplo relleno** — un ejemplo real y completo (no lorem ipsum)
5. **Notas de uso** — 3–5 reglas prácticas para ese formato específico

### Reglas de escritura

- Sin emojis en el cuerpo del guion (compatible con voz en off de IA)
- Máximo 2 oraciones por beat
- Corchetes en MAYÚSCULAS: `[HOOK]`, `[PUNTO 1]`, `[CTA]`
- Sin muletillas de inicio ("Hola a todos", "No olvides darle like")
- Los CTAs deben ser una pregunta o una acción directa — nunca "suscríbete para más"
