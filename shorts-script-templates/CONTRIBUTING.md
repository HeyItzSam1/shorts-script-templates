# Contributing / Cómo contribuir

## English

Thanks for wanting to contribute. This repo grows by creators sharing what works.

### How to add a template

1. Fork this repo
2. Create your file inside the right folder: `templates/[lang]/[niche]/hook-[format].md`
3. Follow the [template format guide](tools/template-guide.md) exactly
4. Submit a pull request with a short description of what the template does

### What we accept

- New formats not yet covered
- New niches (propose in an issue first)
- Fixes to existing templates (broken structure, unclear instructions)
- Translations of existing templates to the other language

### What we don't accept

- Templates that require platform-specific trends or sounds (too short a shelf life)
- Scripts that rely on a specific face or persona
- Anything with filler intros ("Hey guys, welcome back")

## Español

Gracias por querer contribuir. Este repo crece cuando los creadores comparten lo que les funciona.

### Cómo añadir un template

1. Haz fork del repo
2. Crea tu archivo en la carpeta correcta: `templates/[idioma]/[nicho]/hook-[formato].md`
3. Sigue la [guía de formato](tools/template-guide.md) al pie de la letra
4. Envía un pull request con una descripción breve de qué hace el template

### Qué aceptamos

- Formatos nuevos que aún no están cubiertos
- Nichos nuevos (propón en un issue primero)
- Correcciones a templates existentes (estructura rota, instrucciones poco claras)
- Traducciones de templates existentes al otro idioma

### Qué no aceptamos

- Templates que dependan de trends o sonidos de plataforma (vida útil muy corta)
- Scripts que requieran una cara o personalidad específica
- Nada que empiece con muletillas de intro ("Hola chicos, bienvenidos")
