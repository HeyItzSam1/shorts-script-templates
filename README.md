## 🚀 How to Use

**1.** Pick a template from the table above  
**2.** Fill in the `[BRACKETS]` with your content  
**3.** Record — the structure is already optimized for retention

Every template includes:
- A fill-in skeleton
- A fully written example
- Usage notes for that specific format

---

## 📐 Script Formats

| Format | Best for | Avg. duration |
|--------|----------|---------------|
| `hook-list` | Facts, tips, rankings | 30–50s |
| `hook-fact-expand` | Myths, counterintuitive data | 25–40s |
| `hook-story` | History, personal experience | 35–55s |
| `hook-question` | Tech, science, controversy | 25–40s |
| `hook-contrast` | Mindset, before/after | 25–40s |
